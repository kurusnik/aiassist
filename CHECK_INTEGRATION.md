# ✅ Проверка интеграции системы меток RAG

## 🚀 Краткая инструкция:

### 1. **Запустите сервер:**
```bash
npm run dev
```

### 2. **Откройте браузер:**
- Основной интерфейс: `http://localhost:3000`
- Демо системы: `http://localhost:3000/sources-demo.html`
- Тест интеграции: `http://localhost:3000/test-integration.html`

### 3. **Что должно появиться в основном интерфейсе:**
- ✅ В сайдбаре секция "Источники ответов"
- ✅ Переключатель "Показывать источники"
- ✅ Панель статистики с 📚 и 💭
- ✅ Легенда с пояснениями иконок

### 4. **Тестирование:**
1. **Включите переключатель** "Показывать источники"
2. **Отправьте запрос** ассистенту
3. **Проверьте ответ** - должен быть с цветным выделением
4. **Посмотрите статистику** - должна обновиться

## 🔧 Если не работает:

### Проблема: Не появилась секция в сайдбаре
**Решение:** Проверьте файл `public/index.html` - секция должна быть после "System prompt"

### Проблема: Переключатель не работает
**Решение:** 
1. Откройте DevTools (F12)
2. Проверьте Console на ошибки
3. Убедитесь что `app.js` загружается
4. Проверьте localStorage: `localStorage.getItem('sourceMarkersEnabled')`

### Проблема: Нет цветного выделения
**Решение:**
1. Убедитесь что переключатель включен
2. Проверьте что модель использует метки
3. Откройте `sources-demo.html` - если там работает, значит проблема в промптах

### Проблема: Статистика не обновляется
**Решение:**
1. Нажмите кнопку "Сбросить статистику"
2. Проверьте localStorage: `localStorage.getItem('sourceStats')`
3. Убедитесь что `updateSourceStats()` вызывается

## 🐛 Распространенные проблемы:

### 1. **Стили не применяются**
**Причина:** CSS стили переопределены другими правилами
**Решение:** Добавить `!important` или увеличить специфичность

### 2. **Метки не парсятся**
**Причина:** Модель не использует правильный синтаксис
**Решение:** Проверить системный промпт в `services/rag/index.js`

### 3. **Статистика не считается**
**Причина:** `updateSourceStats()` не вызывается
**Решение:** Добавить вызов после каждого рендера чата

### 4. **Переключатель не сохраняет состояние**
**Причина:** Обработчик событий не подключен
**Решение:** Проверить `initSourceStats()` в `app.js`

## 📞 Дополнительная помощь:

Если после всех проверок система не работает:

1. **Проверьте консоль браузера** на ошибки JavaScript
2. **Убедитесь что сервер работает** (`http://localhost:3000/health`)
3. **Проверьте что все файлы загружаются** (Network tab)
4. **Сравните с тестовой страницей** `test-integration.html`

Система должна работать после перезагрузки страницы. Если не работает - перезапустите сервер и очистите кэш браузера.
