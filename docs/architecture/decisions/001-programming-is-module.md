# ADR 001: Programming — модуль AiAssist

**Status:** Accepted

## Context

Programming Engine разрабатывается как новый компонент платформы. Возможные варианты архитектуры:
- отдельное приложение с собственным сервером и БД;
- изолированный микросервис;
- модуль внутри существующего AiAssist.

Первый вариант приводит к дублированию инфраструктуры (авторизация, Express-прослойки, работа с БД). Второй — к накладным расходам на межсервисное взаимодействие без очевидной выгоды на текущем этапе.

## Decision

Programming Engine реализован как модуль внутри AiAssist:
- разделяет ту же Express-сессию и middleware;
- использует `middleware/auth` для авторизации;
- регистрирует свои эндпоинты в корневом `index.js`;
- хранится в `services/programming/`.

## Consequences

Положительные:
- единая авторизация без дублирования кода;
- общая инфраструктура (Express, middleware, статика);
- простота добавления новых эндпоинтов.

Возможные ограничения:
- при сильном росте нагрузки модуль нельзя будет масштабировать независимо без рефакторинга;
- архитектурная связанность: изменения в общем middleware влияют на Programming.
