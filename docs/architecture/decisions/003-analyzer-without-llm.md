# ADR 003: Task Analyzer без LLM

**Status:** Accepted

## Context

Task Analyzer должен классифицировать текстовый запрос пользователя: определить тип задачи, язык программирования и предметную область. Возможные подходы:
- использование LLM через OpenRouter;
- использование регулярных выражений;
- использование словарей ключевых слов с простыми правилами.

LLM-подход даёт высокую точность, но создаёт зависимость: анализатор не будет работать без внешнего API, каждый запрос потребляет токены и увеличивает задержку. Регулярные выражения на 500+ строк нечитаемы и сложны в поддержке.

## Decision

Task Analyzer использует словари ключевых слов и скоринговую систему (1 балл за keyword, 2 балла за subkeyword, побеждает правило с максимальным score). Анализатор полностью локальный, не требует внешних вызовов.

## Consequences

Положительные:
- нулевая задержка на классификацию;
- нет зависимости от OpenRouter и расхода токенов;
- правила легко читаются и дополняются;
- работа в офлайн-режиме.

Возможные ограничения:
- точность ниже, чем у LLM (не понимает синонимы и контекст, не распознаёт парафраз);
- для сложных запросов (например, "почини баг в питоновском скрипте, который парсит JSON") классификация может быть неточной;
- требуется поддержка словарей для новых типов задач.
