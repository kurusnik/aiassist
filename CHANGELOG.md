## [1.0.0] - 2026-02-24

### Добавлено

- **Скрипты сборки и развертывания**
  - `scripts/build.js` - сборка проекта
  - `scripts/deploy.js` - развертывание
  - `scripts/migrate.js` - миграции базы данных
  - `scripts/update.js` - обновление
  - `scripts/backup.js` - backup
  - `scripts/installer.sh` - инсталлятор

- **Контейнеризация**
  - `Dockerfile` - конфигурация Docker
  - `docker-compose.yml` - оркестрация контейнеров
  - `nginx.conf` - конфигурация Nginx

- **CI/CD**
  - `.github/workflows/deploy.yml` - автоматическое развертывание

- **Управление версиями**
  - `CHANGELOG.md` - журнал изменений
  - `package.json` - скрипты для управления

## Формат журнала изменений

Этот проект следует формату [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Типы изменений

- **Добавлено** - Новые возможности
- **Изменено** - Изменения в существующей функциональности
- **Удалено** - Устаревшие возможности удалены
- **Исправлено** - Исправления ошибок
- **Безопасность** - Изменения, связанные с безопасностью

### Формат версии

`<major>.<minor>.<patch>`

- **Major** - Несовместимые изменения API
- **Minor** - Обратно совместимые изменения
- **Patch** - Обратно совместимые исправления ошибок
