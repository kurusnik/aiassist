# Changelog

Все заметные изменения в этом проекте будут задокументированы в этом файле.

## [1.1.0] - 2026-07-24

### Добавлено

- **LLM Aggregator** — универсальный провайдер для OpenAI-совместимых API
  - Поддержка OpenRouter, MixRoute и Custom OpenAI-совместимых API
  - UI: пункт "LLM Aggregator" вместо "OpenRouter" в настройках провайдера
  - Выпадающий список Aggregator Type с автозаполнением Base URL
  - OpenRouter → `https://openrouter.ai/api/v1`
  - MixRoute → `https://api.mixroute.ai/v1`
  - Custom — полностью редактируемое поле

### Изменено

- **OpenRouterProvider** — Base URL теперь берётся из сохранённых настроек вместо хардкода
- **Сохранение настроек LLM** — при сохранении агрегатора автоматически:
  1. Очищается каталог моделей (удаляются старые модели)
  2. Вставляется модель из конфига и назначается всем ролям
  3. Выполняется синхронизация моделей с новым провайдером
- **UI** — после сохранения настроек агрегатора автоматически обновляется каталог моделей и список назначений

### Исправлено

- **401 User not found** — модель из настроек агрегатора теперь автоматически назначается всем ролям, устраняя ошибку аутентификации при использовании модели от предыдущего провайдера
- **Список моделей в назначениях** — старые модели удаляются при смене провайдера, в выпадающем списке отображаются только модели текущего провайдера

## Формат журнала изменений

Этот проект следует формату [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Типы изменений

- **Добавлено** - Новые возможности
- **Изменено** - Изменения в существующей функциональности
- **Удалено** - Устаревшие возможности удалены
- **Исправлено** - Исправления ошибок
- **Безопасность** - Изменения, связанные с безопасностью

### Формат версии

`<major>.<minor>.<patch>`

- **Major** - Несовместимые изменения API
- **Minor** - Обратно совместимые изменения
- **Patch** - Обратно совместимые исправления ошибок
