# 📝 Тестовые запросы для проверки системы меток RAG

## 🚀 Для быстрой проверки в основном интерфейсе:

### Запрос 1: Проверка RAG источников
```
Расскажи про структуру API в проекте
```

**Что должно произойти:**
1. Ответ должен содержать `[RAG:SOURCE]` метки
2. Текст в синих блоках 📚
3. Статистика "RAG источников" увеличится

### Запрос 2: Проверка смешанного ответа  
```
Как работает аутентификация в проекте?
```

**Что должно произойти:**
1. Ответ должен содержать и `[RAG:SOURCE]` и `[MODEL:KNOWLEDGE]`
2. Цветное разделение: синий 📚 и серый 💭
3. Статистика обновится по обоим типам

### Запрос 3: Проверка знаний модели
```
Какие лучшие практики для Node.js приложений?
```

**Что должно произойти:**
1. Ответ должен содержать `[MODEL:KNOWLEDGE]`
2. Текст в серых блоках 💭
3. Только "Знания модели" увеличатся в статистике

## 🧪 Если система не отвечает с метками:

### Проблема: Ответы без меток
**Причина:** Модель не использует метки
**Решение:** Проверить системный промпт в `services/rag/index.js`

### Проблема: Нет цветного выделения
**Причина:** Переключатель выключен или стили не применяются
**Решение:**
1. Убедиться что переключатель "Показывать источники" включен
2. Проверить `quick-test.html` - если там работает, значит проблема в интерфейсе

### Проблема: Статистика не меняется
**Причина:** `updateSourceStats()` не вызывается
**Решение:** Открыть консоль и вызвать `updateSourceStats()` вручную

### Шаг 3: Отправка тестового запроса
Отправьте любой из тестовых запросов выше и проверьте:
- [ ] Ответ содержит метки `[RAG:...]` или `[MODEL:...]`
- [ ] Текст выделен цветом (синий/зеленый/серый)
- [ ] Статистика обновилась
- [ ] Иконки отображаются корректно

## ✅ Критерии успешной проверки:

1. **Интерфейс:**

   - [ ] Переключатель работает и сохраняет состояние
   - [ ] Статистика отображается (не 0/0 после запросов)

2. **Парсер:**
   - [ ] `quick-test.html` показывает цветные сегменты
   - [ ] Метки `[RAG:SOURCE]`, `[MODEL:KNOWLEDGE]` парсятся
   - [ ] Сегменты имеют правильные цвета

3. **Интеграция:**
   - [ ] Ответы ассистента содержат метки
   - [ ] Цветное выделение работает в чате
   - [ ] Статистика обновляется после каждого ответа

4. **Демо:**
   - [ ] `sources-demo.html` открывается (может быть без API теста)
   - [ ] Примеры показывают цветное разделение
   - [ ] Легенда с иконками понятна

## 📞 Если ничего не работает:

1. **Проверьте сервер:** `http://localhost:3000/health` должен вернуть `{"status":"ok"}`

2. **Проверьте файлы:**
   ```bash
   ls -la public/*.html  # Должны быть index.html, sources-demo.html, quick-test.html
   ```

3. **Очистите кэш:** Ctrl+F5 в браузере

4. **Проверьте консоль:** F12 → Console, должны быть ошибки если что-то не так

5. **Перезапустите сервер:** 
   ```bash
   Ctrl+C
   npm run dev
   ```

Система должна работать сразу после интеграции. Если нет - проверьте последовательно по чеклисту выше.
