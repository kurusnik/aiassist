# AI Assistant - Персональный AI-помощник

Веб-приложение для работы с различными LLM-моделями через OpenRouter API с сохранением истории диалогов и авторизацией пользователей.

## 🚀 Возможности

- ✅ **Авторизация** - регистрация и вход по логину/паролю
- ✅ **Множественные проекты** - создание и управление проектами
- ✅ **История диалогов** - сохранение в PostgreSQL
- ✅ **Выбор моделей** - GPT-5.2, Claude 4.5 и другие
- ✅ **Автоматическая суммаризация** - при >20 сообщений
- ✅ **Кастомный system prompt** - настройка поведения ассистента
- ✅ **Современный UI** - темная тема, адаптивный дизайн

## 📋 Требования

- Node.js 16+
- PostgreSQL 12+
- OpenRouter API ключ

## 🛠️ Установка

### 1. Клонирование и установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных

Создайте базу данных PostgreSQL:

```sql
CREATE DATABASE testdb;
CREATE USER testuser WITH PASSWORD '1771';
GRANT ALL PRIVILEGES ON DATABASE testdb TO testuser;
```

Создайте необходимые таблицы:

```sql
-- Таблица пользователей
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255),
  email VARCHAR(255) UNIQUE,
  username VARCHAR(50) UNIQUE,
  password_hash VARCHAR(255),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Таблица проектов
CREATE TABLE projects (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  user_id INTEGER REFERENCES users(id),
  summary TEXT,
  model VARCHAR(100),
  system_prompt TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Таблица сообщений
CREATE TABLE messages (
  id SERIAL PRIMARY KEY,
  project_id INTEGER REFERENCES projects(id) ON DELETE CASCADE,
  role VARCHAR(50) NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Примените миграцию для авторизации:

```bash
psql -U testuser -d testdb -f migrations/001_add_auth.sql
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
SESSION_SECRET=your_random_secret_key
PORT=3000
```

Сгенерируйте SESSION_SECRET:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 4. Запуск сервера

```bash
node index.js
```

Сервер запустится на `http://localhost:3000`

## 📖 Использование

### Первый запуск

1. Откройте `http://localhost:3000`
2. Вы будете перенаправлены на страницу входа
3. Перейдите на вкладку "Регистрация"
4. Создайте учетную запись
5. После регистрации вы автоматически войдете в систему

### Работа с проектами

1. **Создание проекта** - нажмите "Новый проект"
2. **Выбор модели** - выберите нужную LLM-модель
3. **Настройка промпта** - отредактируйте system prompt (опционально)
4. **Диалог** - начните общение с ассистентом
5. **Управление** - удаление проекта или сброс диалога

### Доступные модели

- **GPT-5.2 Codex** - для программирования
- **GPT-5.2 Base** - универсальная модель
- **GPT-5.2 Pro** - максимальное качество
- **Claude Opus 4.5** - для SEO и сложных текстов
- **Claude Sonnet 4.5** - универсальная модель

## 🔒 Безопасность

- Пароли хешируются с помощью bcrypt
- Сессии хранятся в PostgreSQL
- Все API эндпоинты защищены авторизацией
- CSRF защита через httpOnly cookies

## 🔧 API Endpoints

### Авторизация
- `POST /register` - регистрация
- `POST /login` - вход
- `POST /logout` - выход
- `GET /auth/check` - проверка авторизации

### Проекты (требуют авторизации)
- `GET /projects` - список проектов
- `POST /projects` - создать проект
- `GET /projects/:id` - получить проект
- `DELETE /projects/:id` - удалить проект
- `GET /projects/:id/messages` - история сообщений
- `DELETE /projects/:id/messages` - сбросить диалог

### Ассистент
- `POST /assistant` - отправить сообщение
- `GET /models` - список доступных моделей
