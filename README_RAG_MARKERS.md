## 🚀 Как использовать:

### Для пользователей:
1. **Включить/выключить систему** - переключатель в интерфейсе
2. **Просмотр источников** - цветовое выделение в ответах
3. **Статистика** - панель с количеством RAG и знаний модели

### Для разработчиков:
```javascript
// Использование парсера
const { parseSourceMarkers, formatHighlightedResponse } = require('./services/rag');

const response = await aiAssistant.ask(query);
const parsed = parseSourceMarkers(response);

// Доступ к сегментам
parsed.segments.forEach(segment => {
  console.log(`${segment.type}: ${segment.content}`);
  console.log(`Источник RAG: ${segment.isSource}`);
  console.log(`Знания модели: ${segment.isModel}`);
});

// Форматирование для фронтенда
const html = formatHighlightedResponse(parsed);
```

### В системных промптах:
Модель автоматически получает инструкции по использованию меток:
- `[RAG:SOURCE]` - для цитат из базы знаний
- `[RAG:ANALYSIS]` - для выводов на основе RAG  
- `[MODEL:KNOWLEDGE]` - для собственных знаний модели

## 🔧 Конфигурация:

### Локальное хранилище:
```javascript
// Включение/выключение системы
localStorage.setItem('sourceMarkersEnabled', true/false);

// Статистика (автоматически обновляется)
localStorage.getItem('sourceStats'); // {"rag": 15, "model": 32}
```

### Переменные окружения:
```bash
RAG_ENABLED=true  # Включить/выключить всю систему RAG
RAG_SIMILARITY_THRESHOLD=0.7  # Порог релевантности
```
