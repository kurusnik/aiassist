const html = document.documentElement; // Загрузка сохранённой темы const savedTheme = localStorage.getItem('theme') || 'dark'; html.setAttribute('data-theme', savedTheme); themeToggle.textContent = savedTheme === 'dark' ? '🌙' : '☀️'; themeToggle.addEventListener('click', () => { const current = html.getAttribute('data-theme'); const next = current === 'dark' ? 'light' : 'dark'; html.setAttribute('data-theme', next); localStorage.setItem('theme', next); themeToggle.textContent = next === 'dark' ? '🌙' : '☀️'; }); ``` ## Что сделано: | Элемент | Улучшение | |---------|-----------| | **Темы** | Тёмная/светлая с плавным переключением | | **Фон** | Градиентные свечения (glow-эффект) | | **Кнопки** | Градиенты, hover-анимации, тени | | **Инпуты** | Focus-glow, кастомный select | | **Чат** | Анимация появления сообщений | | **Адаптив** | Мобильная версия | Все id и структура сохранены — JS будет работать без изменений.
