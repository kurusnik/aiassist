📊 Демонстрация системы выделения источников RAG

Как это работает:
  • Модель использует специальные метки для обозначения источников информации
  • 📚 [RAG:SOURCE] - цитата из базы знаний RAG
  • 📊 [RAG:ANALYSIS] - анализ на основе информации из RAG
  • 💭 [MODEL:KNOWLEDGE] - собственные знания модели
  • Фронтенд автоматически парсит эти метки и выделяет текст разными стилями

Примеры ответов

🔀 Смешанный ответ
[RAG:SOURCE] Согласно API Documentation... [/RAG] [MODEL:KNOWLEDGE] Обычно такие API... [/MODEL]
📚 Только RAG источники
[RAG:SOURCE] PostgreSQL версии 14... [/RAG] [RAG:SOURCE] Конфигурация в .env... [/RAG]
💭 Только знания модели
[MODEL:KNOWLEDGE] Стандартная практика... [/MODEL]
🔄 Без меток (совместимость)
Просто старый ответ без меток источников.

📝 Визуализация ответа

Легенда:
📚 RAG:SOURCE - цитата из базы знаний
📊 RAG:ANALYSIS - анализ на основе RAG
💭 MODEL:KNOWLEDGE - знания модели

Выберите пример слева для демонстрации
